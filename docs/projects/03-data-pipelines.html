Project 3

Data pipelines – from JSON to clean CSV

In this project you design a small, script-based data pipeline that takes the JSON todos dataset from Project 2, selects and cleans fields, and writes a clean CSV file. You will separate the work into simple extract, transform, and load steps.

📄 JSON input 📑 CSV output ⚙️ Extract–Transform–Load 🔁 Reusable scripts
Focus: reading JSON, writing CSV Pattern: extract → transform → load Goal: a simple, repeatable pipeline script

Key concepts

  • Separating data work into extract, transform, and load steps.
  • Using the json module to read structured data from a file.
  • Using the csv module (especially csv.DictWriter) to write structured CSV files.
  • Designing functions that take data in and return data out, without doing I/O.

Study first (15–30 minutes)

  • Python docs: json module (json.load, json.dump).
  • Python docs: csv module, especially csv.DictWriter.
  • A brief overview of “ETL” as reading, cleaning, and writing data.

The pipeline here is small on purpose. The pattern you practice will show up again on larger, real datasets.

Prepare the raw input file

Copy the todos dataset from Project 2 into this project’s data folder. This keeps each project self-contained.

Copy from Project 2

In Project 2 you downloaded the JSONPlaceholder todos dataset as project02/data/todos.json.

For this project, copy that file into project03/data/raw_todos.json. From the root of your repository: 

mkdir -p project03/data
cp project02/data/todos.json project03/data/raw_todos.json

All steps in this project will use project03/data/raw_todos.json as the raw input file and produce a cleaned CSV file as output.

Each script has a focused responsibility: extract from raw JSON, transform records in memory, load to CSV, and orchestrate the full pipeline.

Tasks

Start by extracting and inspecting fields, then add transformation and CSV output. Finally, wire everything into a single pipeline script.

Task 1 · extract – select and reshape fields

Implement the first step of the pipeline that reads raw JSON and produces a simplified list of records.

Requirements

  • Create scripts/extract.py inside project03/.
  • Implement extract_todos(input_path) that:
    • Reads raw_todos.json using the json module.
    • Returns a list of dictionaries containing a selected subset of fields, for example:
      • id
      • userId
      • title
      • completed
  • Optionally write this simplified list to data/todos_clean.json to inspect.

Hints

  • Use json.load to parse the file and list comprehensions to keep only the fields you need.
  • Keep extract_todos focused on reading and selecting fields; it should not clean or convert values yet.

Task 2 · transform – clean and normalize records

Apply simple cleaning and normalization rules to the extracted records to prepare them for CSV output.

Requirements

  • Create scripts/transform.py.
  • Implement transform_todos(records) where records is the list returned by extract_todos.
  • Apply transformations such as:
    • Normalize title:
      • Strip leading and trailing whitespace.
      • Optionally lowercase or keep original case, but be consistent.
    • Ensure completed is in a consistent form, for example:
      • Keep as True/False but ensure type correctness.
      • Or add a new field completed_int with values 0 or 1.
    • Add a derived field such as title_length (length of the title string).
  • Return a new list of dictionaries with the cleaned structure.

Hints

  • Keep transform_todos pure: it should only take in data and return data, without reading or writing files.
  • Think of this step as “data preparation” for later analysis in pandas or other tools.

Task 3 · load – write clean CSV

Implement the final step that writes the cleaned records to a CSV file with a fixed schema.

Requirements

  • Create scripts/load.py.
  • Implement load_to_csv(records, output_path) that:
    • Uses csv.DictWriter from the standard library.
    • Defines explicit fieldnames, for example:
      • ["id", "user_id", "title", "completed", "title_length"]
    • Writes a header row and then all records to todos_clean.csv.
  • Call this function to produce project03/data/todos_clean.csv as the final output.

Hints

  • Open the CSV with newline="" to avoid extra blank lines on some systems.
  • Map userId to user_id or a similar naming convention to keep your CSV schema clear.

Task 4 · pipeline – orchestrate the steps

Wire up the extract, transform, and load steps into a single script that runs the pipeline end-to-end.

Requirements

  • Create scripts/pipeline.py inside project03/.
  • In a main() function:
    • Define input_path = "project03/data/raw_todos.json".
    • Define output_path = "project03/data/todos_clean.csv".
    • Call your functions in order:
      • records = extract_todos(input_path)
      • clean_records = transform_todos(records)
      • load_to_csv(clean_records, output_path)
    • Print a short summary, for example:
      • Number of records processed.
      • Location of the output CSV file.
  • Use if __name__ == "__main__": to run main() when the script is executed.

Optional extension

  • Add basic argument parsing to allow specifying input and output paths from the command line.

Stretch · logging and validation

Add simple logging and validation to make your pipeline more robust.

Optional

Ideas

  • Add basic logging using the logging module to record the start and end of each step, along with the number of records processed.
  • Implement simple validation in the transform step: check that all required keys are present, and collect any invalid records into a separate list or file.
  • Add an option in the pipeline to keep only completed todos or only todos for a specific userId.

Reflection and notes

Think about how separating extract, transform, and load changed the way you write and read your code.

  • Which step felt most straightforward and which required more decisions?
