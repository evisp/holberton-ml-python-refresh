Project 3

Data pipelines – from JSON to clean CSV

In this project you design a small data pipeline that takes the todo records from Project 2, applies simple transformations, and writes a clean CSV file with a stable schema.

Learning goals

  • Organize code into clear extract, transform, and load steps.
  • Use Python data structures to shape and clean records.
  • Practice reading JSON and writing CSV with the standard library.
  • Build a small pipeline script that ties multiple steps together.

Project context

You keep working inside the same personal repository as Projects 1 and 2. Each project lives in its own folder (project01/, project02/, project03/, …), so your codebase grows in a structured way.

This project reuses the todos.json dataset from Project 2. You will copy it into project03/data/raw_todos.json and treat that file as the raw input for your pipeline.

Prepare the raw input file

Copy the todos dataset from Project 2 into this project’s data folder. This keeps each project self-contained.

Copy from Project 2

In Project 2 you downloaded the JSONPlaceholder todos dataset as project02/data/todos.json.

For this project, copy that file into project03/data/raw_todos.json. From the root of your repository: 

mkdir -p project03/data
cp project02/data/todos.json project03/data/raw_todos.json

All steps in this project will use project03/data/raw_todos.json as the raw input file and produce a cleaned CSV file as output.

Each script has a focused responsibility: extract from raw JSON, transform records in memory, load to CSV, and orchestrate the full pipeline.

Task 1 · extract – select and reshape fields

Implement the first step of the pipeline that reads raw JSON and produces a simplified list of records.

Requirements

  • Create scripts/extract.py inside project03/.
  • Implement a function extract_todos(input_path) that:
    • Reads raw_todos.json using the json module.
    • Returns a list of dictionaries containing only selected fields, for example:
      • id
      • userId
      • title
      • completed
  • Optionally write this simplified list to data/todos_clean.json to inspect.

Hints

  • Use json.load to parse the file and then a list comprehension to keep only the fields you need.
  • Keeping extract_todos focused on reading and selecting fields makes later steps easier to reason about.

Task 2 · transform – clean and normalize records

Apply simple cleaning and normalization rules to the extracted records to prepare them for CSV output.

Requirements

  • Create scripts/transform.py.
  • Implement a function transform_todos(records) where records is the list returned by extract_todos.
  • Apply transformations such as:
    • Normalize title:
      • Strip leading and trailing whitespace.
      • Optionally lowercase or keep the original case, but be consistent.
    • Convert completed into a more explicit representation, for example:
      • Keep a boolean but ensure it is always True or False.
      • Or create a new field completed_int with values 0 or 1.
    • Add a derived field such as title_length (the length of the title string).
  • Return a new list of dictionaries with the cleaned structure.

Hints

  • Keep transform_todos pure: it should not read or write files, only transform data.
  • Think of this step as “data preparation” where you ensure fields are consistent and ready for downstream use.

Task 3 · load – write clean CSV

Implement the final step that writes the cleaned records to a CSV file with a fixed schema.

Requirements

  • Create scripts/load.py.
  • Implement a function load_to_csv(records, output_path) that:
    • Uses csv.DictWriter from the standard library.
    • Defines explicit fieldnames, for example:
      • ["id", "user_id", "title", "completed", "title_length"]
    • Writes a header row and then all records to todos_clean.csv.
  • Call this function to produce project03/data/todos_clean.csv as the final output.

Hints

  • Open the CSV file with newline="" to avoid extra blank lines on some systems.
  • Map userId to user_id or a similar naming convention to keep your CSV schema clear.

Task 4 · pipeline – orchestrate the steps

Wire up the extract, transform, and load steps into a single script that runs the pipeline end-to-end.

Requirements

  • Create scripts/pipeline.py inside project03/.
  • In a main() function:
    • Define input_path = "project03/data/raw_todos.json".
    • Define output_path = "project03/data/todos_clean.csv".
    • Call your functions in order:
      • records = extract_todos(input_path)
      • clean_records = transform_todos(records)
      • load_to_csv(clean_records, output_path)
    • Print a short summary, for example:
      • Number of records processed.
      • Location of the output CSV file.
  • Use if __name__ == "__main__": to run main() when the script is executed.

Optional extension

  • Add basic argument parsing so you can specify input and output paths from the command line.

Stretch goals (optional)

Extra challenges for when you want to push your data-pipeline skills a bit further.

Optional extensions

  • Add basic logging using the logging module to record the start and end of each step, along with the number of records processed.
  • Implement simple validation in the transform step: check that all required keys are present in each record and collect any invalid records into a separate list or file.
  • Add an option in the pipeline to keep only completed todos or only todos for a specific userId.

Reflection and notes

Slow down and think about how separating steps changes the way you design and read your code.

Project notes

Create a file project03-notes.md inside project03/ and write short answers to these questions:

  • How did separating extract, transform, and load affect your code organization?
  • Which step felt most straightforward and which required more decisions?
  • If you had to plug another JSON dataset into this pipeline, what would you need to change?

These reflections help you connect small pipeline exercises to larger data workflows you may encounter in future projects.
