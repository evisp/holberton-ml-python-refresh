Project 4

Data skills – exploratory analysis with pandas

In this project you use pandas to explore the cleaned todos dataset from Project 3. You will inspect the data, compute simple statistics, and create basic visualizations, saving figures as files.

📊 pandas DataFrames 🔎 EDA 📈 Plots 💾 Saved figures
Focus: loading CSV, describing data, grouping Tools: pandas, matplotlib (or built-in plotting via pandas) Goal: a few saved plots and text summaries

Key concepts

  • Reading CSV files into pandas DataFrames.
  • Inspecting data with head, info, and describe.
  • Grouping and aggregating by key columns (for example user_id).
  • Creating simple plots (histograms, bar charts) and saving them as image files.

Study first (15–30 minutes)

  • Install pandas if you do not have it: run pip install pandas in your virtual environment.
  • Read a short “getting started” guide for pandas (DataFrames, columns, basic methods).
  • Skim a tutorial on basic EDA with pandas (loading, describing, grouping).

Make sure you can import pandas (import pandas as pd) in a Python shell before starting the tasks.

Prepare the cleaned CSV file

Copy the CSV produced in Project 3 into this project’s data folder. All analysis will use this file.

Copy from Project 3

In Project 3 you generated a cleaned CSV file project03/data/todos_clean.csv.

For this project, copy that file into project04/data/todos_clean.csv. From the root of your repository: 

mkdir -p project04/data
cp project03/data/todos_clean.csv project04/data/todos_clean.csv

All tasks in this project will use project04/data/todos_clean.csv as the dataset.

Tasks

Load the CSV into pandas, inspect it, compute basic statistics, and then create and save simple plots.

Task 0 · load and first look

Get comfortable loading the CSV into pandas and performing basic inspection.

Requirements

  • Create scripts/eda_overview.py inside project04/.
  • In this script:
    • Import pandas as pd.
    • Load data/todos_clean.csv into a DataFrame (df).
    • Print:
      • The first few rows (df.head()).
      • The shape (df.shape – number of rows and columns).
      • Data types (df.dtypes).
      • Basic info (df.info()).

Hints

  • Think of this step as “getting acquainted” with the dataset in pandas form.
  • In your notes, write down: number of rows, number of columns, and what each column seems to represent.

Task 1 · descriptive statistics and distributions

Compute simple statistics and look at basic distributions of key columns.

Requirements

  • Extend eda_overview.py or add functions inside it.
  • Compute and print:
    • df.describe() for numeric columns (such as title_length and any numeric completion flag).
    • Value counts for completion status (df["completed"].value_counts() or similar).

Hints

  • Use df["completed"] or df["completed_int"] depending on your Project 3 output.
  • Look at minimum, maximum, mean, and quartiles for title_length to understand how long todo titles tend to be.

Task 2 · grouping and simple aggregations

Use groupby to understand per-user patterns in the todo data.

Requirements

  • Create scripts/eda_grouping.py.
  • In this script:
    • Load todos_clean.csv into a DataFrame.
    • Compute:
      • Number of todos per user (for example df.groupby("user_id")["id"].count()).
      • Completion rate per user (for example mean of a numeric completion flag).
    • Print:
      • The user with the most todos.
      • The user(s) with the highest completion rate.

Hints

  • groupby followed by aggregation (like .count() or .mean()) is a powerful pattern in pandas.
  • Sorting the results (for example .sort_values()) can help you identify top users quickly.

Task 3 · filtering and questions

Use filtering to answer simple questions about the data.

Requirements

  • Create scripts/eda_filters.py or extend eda_grouping.py.
  • Answer questions such as:
    • Which todos have a title_length above a chosen threshold?
    • How many completed vs pending todos are there?
    • For a given user_id, how many todos are completed and how many are pending?
  • Use boolean indexing on the DataFrame (for example df[df["completed"] == 1]).

Hints

  • Think of each question as “filter rows, then count or summarize”.
  • Chain conditions using & and | with parentheses when you need multiple filters.

Task 4 · plots – save simple figures

Create a few basic plots and save them to image files so you can view and share them.

Requirements

  • Create scripts/eda_plots.py.
  • Use pandas plotting or matplotlib to create:
    • A histogram of title_length, saved as figures/title_length_hist.png.
    • A bar chart of completed vs pending todos, saved as figures/completion_bar.png.
    • A bar chart of completion rate per user (or number of todos per user), saved as figures/completion_by_user_bar.png.
  • Make sure you create the figures/ folder before saving.

Hints

  • Use plt.savefig("project04/figures/filename.png", dpi=150) to save plots if you use matplotlib.
  • Keep plots simple: clear labels, readable axes, and no need for advanced styling.

Optional · summary script

Create a small script that prints a text summary of key EDA findings.

Optional

  • Load todos_clean.csv into pandas.
  • Print:
    • Overall shape and basic describe() output.

Stretch goals (optional)

Extra EDA challenges for when you want to go a bit further.

Optional extensions

  • Save a short EDA report to a markdown file (project04/eda_report.md) summarizing your main findings.
  • Add another figure of your choice (for example, a boxplot of title_length per user) and save it in the figures/ folder.

Reflection and notes

Connect your EDA work to how you think about data and future projects.

Project notes

Create a file project04-notes.md inside project04/ and write short answers to questions like:

  • What was the most surprising pattern you found in the todo data?
  • Which pandas operation (describe, groupby, filtering) felt most powerful or useful?
  • How does exploring your own pipeline output help you understand the importance of data quality?

These reflections help you see EDA as a core skill in working with data, even before any ML is involved.
