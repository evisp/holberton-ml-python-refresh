How to work with this prep

Use a simple Study → Build → Reflect loop on each project. The goal is to rebuild skills in a way that matches Holberton’s learning style.

1 Study the concepts

Before you start coding, skim the “Key concepts” and “Study first” sections at the top of each project page.

  • Open the project page and read the short overview.
  • Review the core ideas listed under “Key concepts”.
  • Spend 15–30 minutes with 1–2 of the suggested links.

2 Build the projects

Implement the tasks step by step, keeping each project inside its own folder in your repository.

  • Clone this repository into your own GitHub account.
  • Create a virtual environment and install any dependencies.
  • Work through tasks in order, using the expandable cards as checkpoints.

3 Reflect and iterate

Capture what you refreshed, what tripped you up, and what to revisit before starting the ML program.

  • Keep a short notes file in each project (for example project01-notes.md).
  • Write down patterns you rediscovered or struggled with.
  • Review your notes before moving to the next project or to ML content.
