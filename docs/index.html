How to work with this prep

Follow a simple Study → Build → Reflect loop on each project. The goal is to rebuild skills in a way that matches Holberton’s learning style.

1 Study the concepts

Before you start coding, skim the “Key concepts” and “Study first” section at the top of each project page. Spend 15–30 minutes revisiting the ideas and links that matter for that project.

Quick checklist

  • Clone this repository into your own account.
  • Create a virtual environment and install any dependencies you need.
  • Open the project page, read all tasks, and skim the suggested resources.

  1. 2 Build the projects

    Start from Project 1 or jump straight to the area you want to strengthen most. Implement the tasks one by one, keeping each project inside its own folder in your repository.

  2. 3 Reflect and iterate

    For each project, keep a short notes file (for example project01-notes.md) where you capture what you refreshed, what tripped you up, and what you want to revisit before starting the ML program.
