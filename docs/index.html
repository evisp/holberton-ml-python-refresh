Python & Data Foundations

Refresh your Python.
Build for Machine Learning.

A self-paced, project-based prep path to rebuild your Python, data structures, and data handling skills before the Holberton Machine Learning program.

Start with Project 1 Browse all projects

What you’ll practice

  • Python scripting and CLI utilities
  • Core data structures: lists, dicts, sets
  • Working with JSON, CSV, and files
  • Basic pandas and exploratory analysis

Why this prep exists

Holberton’s learning model is built around real projects, autonomy, and peer learning. This prep mirrors that approach so you re-enter the ML program ready to build from day one.

No lectures, no scripted walkthroughs—just clear objectives, guidance, and space to experiment, make mistakes, and grow.

Build confidence

Revisit core Python patterns in small, focused tasks before combining them in larger projects.

Think in data

Practice reading, transforming, and structuring data the way you will in real ML workflows.

Match the pace

Align your habits with Holberton expectations: self-directed research, clean code, and reflection.

How to work with this prep

  1. 1 · Clone and set up

    Clone this repository, create a virtual environment, and install any required dependencies.

  2. 2 · Pick a project

    Start from project 1 or jump to the area you want to strengthen most. Read all tasks before coding.

  3. 3 · Build, test, reflect

    Implement tasks, add tests or checks where relevant, and keep short notes on what you learned.
